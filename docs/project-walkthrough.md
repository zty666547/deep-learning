# 项目详细理解手册（持续更新）

本手册用于理解方法、阅读真实结果和准备视频/答辩。它与 `quality-review.md` 配套：前者解释方法，后者说明哪些结论已核验、哪些工作尚缺。

## 1. 研究对象与矩阵含义

把一条染色体按固定长度划分成bin，每个bin是一段连续DNA。接触矩阵中的 `(i,j)` 描述第i段与第j段的接触计数。高计数通常表示在实验中更常被观测到接触，但计数还受覆盖和测序深度影响。

矩阵两个轴都是同一条基因组的坐标，故通常对称。主对角线附近的计数往往较高，因为基因组位置相近的DNA片段更容易接触。解读局部结构时，需要区分正常的距离衰减、特殊接触形态和技术性覆盖缺口。

`.cool`是保存bin坐标与稀疏接触计数的格式。我们按局部区域读取矩阵，没有把完整10 bp全基因组矩阵展开为巨大密集数组。

## 2. 为什么读取、池化与归一化要分别处理

读取决定使用哪个染色体和基因组区间。池化改变空间分辨率，归一化改变数值表示，两者作用不同。

10 bp数据按16×16块求和，得到160 bp数据；20,480 bp区间对应128×128矩阵。求和保留该块的接触计数，能降低计算量，但丢失细节。

`log1p(x)=log(1+x)`降低大计数对训练的支配，保留零值。它不是ICE/KR平衡，也不是距离校正。报告里应准确写“计数求和池化与log1p变换”，不能把它笼统说成消除了所有测序偏差。

## 3. 数据划分如何避免泄漏

相邻结构的局部窗口可能重叠。如果随机拆分，训练样本与测试样本可能包含相同的接触像素，会高估性能。当前使用连续基因组区段划分，并排除跨分界线窗口。

两个生物学重复作为输入通道：同一区域的两个矩阵同时提供给模型。这测试的是新基因组区域上的泛化；并不等于训练于rep1、测试于完全独立rep2。

训练集用来更新参数，验证集选择模型/阈值，测试集用于按预先固定协议报告结果。不能看测试结果后不断调整参数再声称它是未使用过的测试集。

## 4. 任务一：已知结构识别

CHID、CHIN、OPCID来自课程提供的标注。最初每条标注对应一个窗口，CNN做三分类。卷积层学习局部模式，池化降低尺寸，最后输出三个类别分数。

标注审计发现跨类别区间重叠。多标签补充实验把相连的冲突标注合并为区域，对三种标签分别预测是否存在。Sigmoid输出三个独立概率，允许同时给两个标签。

多标签损失是二元交叉熵：每类单独比较预测与0/1标签。正样本权重从训练集计算，缓解少数标签不足。概率阈值只在验证集选择。

Precision回答“预测为阳性的区域中有多少正确”，Recall回答“真实阳性中识别出多少”，F1综合两者。Macro F1对每类等权，Micro F1把所有标签的计数合并；CHIN占比较高时两者可能明显不同。精确匹配要求一个区域的所有标签都正确，因此容易受到标签组合与多数类策略影响。

三分类与多标签需要分别呈现，不能直接比较两种问题的Accuracy/F1并认定模型改进。正式报告还要保留任务要求对应的三分类证据。

## 5. 任务二：疑似新结构候选

扫描多个基因组窗口，计算强度、距离带、中心富集、稀疏度和纹理等特征。质量检查先识别缺失及零信号横纵条带，否则聚类可能把覆盖缺口当成特殊结构。

标准化让不同单位的特征可比较；PCA用少数线性组合概括变化；K-means按特征距离分组。轮廓系数用于比较不同聚类数的分离程度，但不能说明某簇对应新的生物学结构。

主流程进一步排除与已知结构重叠的窗口，计算到已知窗口的特征距离，并要求跨重复一致和多个相邻窗口支持。相邻命中窗口合并为区域，但其支持数量不是独立生物学重复数。

阈值敏感性分析检查：稍改相关阈值或新颖度分位数，候选是否还存在。稳定候选更适合优先复核；高相关、稳定、无已知重叠仍不足以证明新结构。

仓库另有历史粗步长探索。正式材料统一采用`task2-main-v1`的5个候选，并附基因组坐标；历史8候选不进入报告主结果，不能混用两套`candidate_002`。

### 为什么去对角线和扣除距离趋势

假设两张接触图都只是“距离越近计数越高”，即使没有特殊结构，整图相关性也可能很高。专项核验先排除距离小于800 bp的像素（160 bp×5），再把每条偏对角线上的`log1p`均值分别从两个重复中扣除，计算剩余纹理的相关性。只有距离趋势、没有纹理时残差为常数，相关性未定义，不能填成伪造的0或1。

这不是全基因组observed/expected归一化，而是每个窗口内部去距离均值。保留的外侧偏对角线至少有3个像素。核验覆盖所有质量合格窗口，候选代表、候选邻域、已知重叠和无标注背景分开描述；背景不是确定的生物学阴性，重叠窗口也不是独立样本。高残差相关只支持一致性，不直接支持新颖性，不能根据核验结果重新挑选更漂亮的候选。

### 已知召回、背景与失败对照怎样理解

全滑窗覆盖344条标注是扫描几何覆盖，不能当识别率。质量过滤会损失覆盖，取不重叠网格后得到187窗口（141已知重叠、46无标注背景）。五段基因组轮流留出，每次只用训练区拟合缩放和固定逻辑回归，训练/测试间再留20,480 bp缓冲。

AUC衡量已知重叠窗口分数高于背景窗口的排序能力，0.5为无排序能力基准；平衡准确率给召回与特异度等权。全部预测阳性虽有100%召回，特异度为0%，平衡准确率仅0.5。无标注背景可能有尚未标注的结构，不能当确定阴性。

原8特征平均AUC只有0.5582，落在100次打乱标签范围；形态/重复6项约0.4971。现有特征可做探索聚类，却尚未显示稳定已知/背景区分能力，这是需要解决的缺口。新表征应单独标识探索版本，承认测试区域已看过。见[特征核验](task2-feature-benchmark.md)。

后续固定空间分块36项、去距离纹理72项，并做rep1→rep2与反向的新区域留出，AUC仍约0.53–0.56。这个结果说明简单增加空间维度或去距离包络尚未解决问题。预先提交方案后才跑实验，完整保留弱结果；可能需要重审“任意已知重叠”的标签及结构位置/尺度。见[形态探索](task2-shape-exploration.md)，不是全新未见测试。

### 候选从扫描到独立条件核验的完整链

讲任务二时，建议按“生成候选—过滤伪影—描述形态—固定坐标—独立核验”顺序说明，而不是只展示聚类图：

| 阶段 | 做法与当前证据 | 为什么需要 / 不能说明什么 |
| --- | --- | --- |
| 输入与切窗 | WT 37°C双重复，10 bp矩阵求和池化到160 bp；以20,480 bp窗口、2,560 bp步长扫描1,807个窗口 | 固定窗口让每张图大小可比；相邻窗口高度重叠，不是独立样本 |
| 质量筛查 | 以有限值、非零像素和零bin连续长度检查，1,498个窗口通过；309个排除 | 防止覆盖缺口被当成新形态；这是质量过滤，不是生物学标签 |
| 特征与聚类 | 提取8个强度、稀疏度、距离衰减、中心富集、纹理和重复特征；稳健缩放、PCA、K-means；`k=2`轮廓系数最高0.4073 | 聚类总结相似窗口；两个簇均含大量已知结构，所以不能给簇贴“新结构”名称 |
| 候选定义 | 排除已知结构重叠；要求重复相关≥0.90、满足零bin质控、新颖度最高10%、至少2个相邻窗口支持；得到25个命中窗口、合并成5个区域 | 每条都是明确可复现的计算规则，但阈值不是生物学金标准；支持窗口不能算多个实验重复 |
| 原始重复核验 | 去掉<800 bp接触，再按窗口内每条偏移的均值中心化；5个候选的WT距离中心化相关为0.709–0.931 | 排除共同距离衰减造成的虚高相似；仍在WT数据里选择，存在选择偏差 |
| 条件迁移与背景对照 | 两种突变各双重复；比较候选完整区域及其20,480 bp代表窗口。独立突变条件下，候选代表与329个无标注背景的相关中位数在原始/CPM四种设置中均更高 | 突变数据没有参与候选筛选，提供额外可重复性支持；但背景未被证实为阴性、窗口互相重叠、候选仅5个，不能给出显著性或因果结论 |
| 计数与尺度敏感性 | CPM后候选—背景方向仍一致；80/160/320 bp下候选跨条件相关都为正，候选005排序最高；相关强度随池化粗化明显上升 | 总库CPM不是局部覆盖/距离校正；粗分辨率会平滑图像，因此不同分辨率的r不能当作独立证据或直接比较成生物效应 |

这里有三个容易混淆的“最佳”：候选004在18组候选阈值组合中最常复现，是**参数稳定性**；候选005在不同突变和分辨率下通常有最高的**纹理相关**；两者都不等于被确认是新结构。候选—背景的逐条件数值见[独立突变对照](task2-mutant-background-control.md)，跨条件和CPM见[迁移审查](task2-condition-transfer-audit.md)，不同分辨率见[尺度审查](task2-resolution-audit.md)。

面向视频，可以说：“我们得到5个需要进一步验证的候选。它们在未参与筛选的突变重复中，比无标注背景呈现更高的距离中心化重复一致性；这一方向在总库CPM下保持。但候选数少、背景窗口互有重叠，且相关强度受分辨率影响，所以目前把它作为支持性证据，而不是统计显著的新结构发现。”

## 6. 任务三：把结果放回基因组坐标

当前任务三使用WT 37°C、ΔstpA、ΔhnsΔstpA各两个生物学重复。六份10 bp矩阵求和池化为160 bp；对每个bin统计环状染色体上中心距离不超过10 kb的非对角线接触，再按全库计数换算CPM。每个条件先对两个重复等权平均，三条件再等权求灰色总体均值。

每10 kb区间用共享横坐标画四层：条件曲线、三条件均值、蓝色RefSeq基因、橙色CHIN/OPCID。465个连续区间覆盖4,641,652 bp全染色体，末段按实际边界截短。CPM只校正全库计数差异，不校正距离衰减或局部覆盖，不等于基因表达，也没有统计检验。GFF参考版本已核对；结构表344条区间全部与10 bp COOL边界一致，支持直接采用0-based左闭右开，论文未在表头明确闭开规则，详见[坐标审计](annotation-coordinate-audit.md)。

## 7. 任务五：超分辨率与公平对照

160 bp像素覆盖2×2个80 bp像素。当前数据使用求和，因此低分辨率计数是对应四个细像素的总和。直接上采样这个总和，会把尺度差异当成重建误差。

修正版先计算：`low_corrected = log1p(expm1(low_log_counts)/4)`。除以4发生在计数空间，不能直接把log值除以4。这样低分辨率输入与高分辨率目标处在相同的平均细像素强度尺度。

插值通过邻近像素估计细网格；CNN学习插值附近的残差。修正版对二者使用相同的训练集标准化统计，输出对称矩阵，并对比相同目标。绘图统一色标，防止色彩范围变化制造视觉改善。

PSNR由像素误差与指定动态范围计算，越高表示误差相对更小。局部SSIM比较局部亮度、对比度和结构；本实现使用7×7均匀窗口、总体矩统计、有效窗口平均，逐重复独立计算。旧全图矩SSIM只保留为历史代码，不与新局部SSIM混报。

这个实验是同一数据的降分辨率重建，需要明确不是独立低分辨率实验到高分辨率实验的外部验证。提高图像指标也不能证明恢复出了新的真实接触。

## 8. 你最终应能讲清楚的问题

1. 每项任务的输入、输出和评价指标是什么？
2. 为什么选择20,480 bp窗口和160 bp分辨率？对照说明了哪些取舍？
3. 为什么避免随机打散基因组窗口？两个重复作为通道意味着什么？
4. 标注重叠如何影响三分类？为什么多标签只是另一种问题定义？
5. 高重复相关性为何不是新结构的充分证明？
6. 候选004参数稳定和候选005纹理相关最高，分别代表什么？为什么不能都简称“最佳候选”？
7. 突变背景、CPM和80/160/320 bp审查各自排除了什么风险，又留下什么限制？
8. 为什么需要阴性对照、去对角线验证、已知结构召回？这些是否已经完成？
9. 160 bp计数为何要除以4？为什么不能直接把log值除以4？
10. CNN是否在公平尺度下超过插值？是否每个种子都超过？
11. 当前最可信结论与最大的未解决限制分别是什么？
12. 从原始数据到最终图表需要执行哪些命令，如何确认复现成功？

后续最终讲解会用这些问题组织，从基础概念、具体样本、设计取舍到结果解释逐层展开。
