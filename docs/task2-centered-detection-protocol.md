# 任务二：标注中心检测与全基因组留出召回协议

2026-10-14，版本`task2-centered-detection-v1`。本协议在真实拟合与评价前提交。用户要求核心任务全部完成前停止PPT制作；现有草稿保留，不继续加工。优先检验任务二已有标签尺度问题，不预写性能提升或新结构结论。

## 问题定义

旧187窗口对照采用“20,480 bp窗口与已知结构任意正长度重叠”标签，共141正例/46无标注背景；小结构在边缘时仍是正例。新对照使用344标注中心对齐160 bp网格，128 bin完整窗口（约20,480 bp），相同起止坐标去重并保留全部标注ID/类别；46背景沿用固定起点20,480 bp网格、原QC通过且不与任意标注重叠的窗口。

正例不是新生物学样本，背景不是已确认阴性；不同标注的上下文可重叠，类别冲突不决定本项二分类标签。新旧人口与问题定义不同，新AUC不得替换旧弱结果。用于科学检查的模拟矩阵仅出现在工程测试。

## 数据与质控

使用已有WT1/WT2 160 bp真实池化矩阵、`structures.csv`及1,807窗口扫描表。中心窗口逐重复复用原QC规则：总计数≥1、非零比例≥0.01、有限比例≥0.99、零行与最大连续零行比例≤0.03；失败身份/原因全部保留，汇报344标注的总覆盖和QC排除，不能只报成功样本。阴性背景已满足原双重复QC，不按拟合结果增删。

形态输入沿用已冻结纹理变换：128×128计数→log1p→每距离减均值（≥800 bp，最外两距离排除）→每窗口单位RMS、截断[-5,5]→2×2均值池化成64×64。仅用自身矩阵，不拟合全库统计。去掉全窗计数尺度不能排除所有密度/测序噪声信息，另设密度对照。

## 防泄漏与相关样本

沿染色体长度4,641,652 bp均分五块，以窗口中心确定留出块。完整留出块两端先各外扩10,240 bp，覆盖所有中心在块内的扫描窗口；再与实际测试窗口范围取并集，训练窗口必须在其外并留20,480 bp保护带。第0/4块另外剔除染色体另一端20,480 bp，考虑环状相邻。WT1训练，WT2同坐标留出评价；WT1自身留出另列，不把同坐标重复说成独立外部生物学验证。

训练/评价各自从提供的子集计算重叠窗口连通组。每类总权重1/2，每类内连通组等权，组内同类窗口等权；用于固定BCE训练和组件加权指标。另保留普通逐窗口指标、每标注身份与全扫描召回，权重不能制造独立样本或独立实验重复。

## 固定模型与对照

复用原纹理编码器三层卷积8/16/32通道、GroupNorm/ReLU、2×2全局池化128维，新增单线性二分类头。没有对比投影头、预训练或旧测试标签调参。CPU1线程、确定性算法、种子2026/2027/2028，每折每种子最终第20轮，AdamW lr=0.001/weight_decay=0.0001，随机batch≤32，组件等权BCE。无验证挑权重、早停、超参数搜索或结果不佳后的轮数修改。

对照一：两维密度（log1p总计数、非零比例），WT1训练/WT2评价、训练专属中位数/IQR、固定L2逻辑回归0.01。对照二：每个CNN的相同初始化随机编码器128维，WT1训练专属逻辑回归/WT2评价，同惩罚与0.5阈值。逻辑回归沿用旧类平衡实现；不与CNN的组件权重假称完全同优化。保存所有五折/三种子训练记录、权重、留出特征/概率/身份、组件权重与拟合参数。

主指标为WT2五折组件加权AUC（逐种子折均及三种子汇总），同时报告各折、逐窗口AUC、0.5召回/特异度/平衡准确率、逐类别正例召回。不得只选种子或最佳折；未设事后筛选阈值。旧187窗口同坐标留出预测另列，仍采用旧任意重叠标签。

## 全基因组扫描与科学边界

每个QC通过扫描窗口使用其所属留出块的三个模型，在WT2上生成三种子平均结构中心概率；各折训练保护覆盖整块，扫描窗口未进入拟合。原QC失败窗口不计为通过，全部1,807身份保留；344标注按中心±1,280 bp内QC扫描窗口的最大平均概率≥0.5计算召回，无可评分邻窗计为未召回并单列。±1,280固定为2,560 bp步长的一半，不根据图表调整。

该分数衡量已知中心相似性，不是新颖性概率或结构身份；中心正例拟合得到的128维监督特征也不是无监督新类证据。五个主候选、旧全局两簇及其失败对照不被本实验重新筛选/确认。若学习未优于控制，应记录负面结果；若有提升，仍需独立无标注形态簇与新颖性证据才能称任务二科学完成。
