# 任务五：配对空间组不确定性与去距离保真

日期：2026-10-13。沿用`215a307`事前冻结的[核验协议](task2-task5-validation-protocol.md)，不重训、不调参、不修改原测试集或严格history失败记录。运行一次真实核验，再在普通wheel安装环境按同一协议复算一次验收，数值未改变；只补图中空间组数量标识。

## 输入与口径

三个`outputs/task5_corrected/seed_*/test_reconstruction.npz`各含41个结构、两个通道和三个方法矩阵。核对目标/双三次/元数据逐数组相同，重算492行PSNR/SSIM/MSE并在1e-12容差内核对旧CSV。来源哈希见[结果快照](task5-paired-uncertainty-summary.json)。

每结构平均两通道及三个种子的**指标**，只有41个配对结构，不把246个通道×种子记录当独立样本。本项不同于旧结构/距离分层评价先平均两通道矩阵再算MSE，两口径不混写。所有delta统一正值表示CNN较好：PSNR/SSIM/r为CNN减双三次，MSE为双三次减CNN。

新保真量为已经log1p的图，保留800 bp及更远偏移，排除仅剩1–2像素的最外围偏移，各方法分别减去各距离的均值后计算Pearson r。没有第二次log1p，也不是全基因组O/E、结构边界召回或生物学机制检验。

## 不把相邻窗口当独立样本

固定三种空间组，组间整组放回抽样10,000次，seed=2026，统计结构加权配对均值，并报告删去一组后的范围。跨界窗口合并所触及100 kb网格，故重叠窗口不被错误拆成不同抽样单位。

| 预设分组 | 空间组数及大小 | PSNR增益95%百分位区间 | 残差r增益95%区间 | 删组PSNR均值范围 |
| --- | --- | --- | --- | --- |
| 正长度窗口重叠连通分量 | 13组；1/1/4/1/2/6/1/1/1/1/2/14/6 | 0.321101–0.340949 | 0.007503–0.010690 | 0.328265–0.337533 |
| 两侧扩大20,480 bp后重叠分量 | **仅2组；7/34** | 0.325269–0.335429 | 0.008988–0.009417 | 0.325269–0.335429 |
| 跨界传递合并100 kb网格 | 5组；6/1/8/4/22 | 0.322232–0.339759 | 0.006849–0.009947 | 0.325175–0.336813 |

![固定测试区配对组bootstrap；图中明确显示空间组数量](figures/task5_paired_uncertainty.png)

**2组方案的区间尤其不能解释为高精度证据**：抽样组合只有有限几种，增加到10,000次并不增加空间/生物学信息；其窄区间只是两个现有组平均结果相近。5组和13组同样有限，长程空间依赖仍可能存在。不选最窄区间当最终可靠性，也不输出p值。

详尽逐结构配对表见[41行小表](task5-paired-structure-metrics.csv)，所有指标的区间、删组范围和组大小见JSON。原始492行通道指标与完整分组表留在忽略目录。

## 复算与尚缺

普通wheel安装验收清除PYTHONPATH、隔离模式复算，492行通道表、41行配对表、20行三方案空间组表及全部摘要逐值一致。安装环境复用旧锁定依赖，不是新下载全部依赖或跨平台验证，见[中文日志](development-log.md)。

```bash
PYTHONPATH=src python scripts/audit_super_resolution_uncertainty.py \
  --reconstruction-dir outputs/task5_corrected \
  --output-dir outputs/task5_uncertainty_new
```

入口拒绝覆盖旧输出，验证指标与输入身份后再写文件。固定测试数据存在相关性，低分辨率由同一目标聚合而来；本核验增强内部像素保真与不确定性报告，**不是独立低深度实验或跨条件验证**。原始三模型重训history最大差1.32e-8，冻结1e-12标准下仍`diverged`，本项通过不替换原凭据，也不改变已有PSNR性能结论。
