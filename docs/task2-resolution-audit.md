# 任务二：固定候选的分辨率稳健性审查

日期：2026-10-10。候选仍固定为`task2-main-v1`的5个合并区间，未根据本轮结果重新筛选。

## 预设方法

- 直接从WT、ΔstpA、ΔhnsΔstpA各两个10 bp源COOL中提取候选全区间；只在局部矩阵上分别按8、16、32倍求和池化到80、160、320 bp，不生成整基因组派生文件。
- 使用同一坐标、同一原始实验及同一距离中心化相关定义；标称排除800 bp以内的接触。由于偏移只能取整数bin，80/160 bp分别排除10/5个bin（恰为800 bp），320 bp排除3个bin（实际960 bp）。
- 报告条件内双重复及WT与突变体的4种交叉重复配对中位数。分辨率是同一数据的重采样/平滑尺度，不是额外的生物学重复。
- 只做描述性尺度稳健性检查，不计算p值，不作新结构、突变因果或独立复现声明。

## 复现

```bash
PYTHONPATH=src .venv/bin/python scripts/audit_candidate_resolution.py \
  --candidates docs/task2-candidate-registry.csv \
  --wt-rep1 data/raw/GSE272159_37C_rep1.mapq_30.10.cool \
  --wt-rep2 data/raw/GSE272159_37C_rep2.mapq_30.10.cool \
  --dstpa-rep1 data/raw/GSM8950761_DstpA_rep1.MG1655.mapq_30.10.cool.gz \
  --dstpa-rep2 data/raw/GSM8950762_DstpA_rep2.MG1655.mapq_30.10.cool.gz \
  --double-rep1 data/raw/GSM8950763_DhnsDstpA_rep1.MG1655.mapq_30.10.cool.gz \
  --double-rep2 data/raw/GSM8950764_DhnsDstpA_rep2.MG1655.mapq_30.10.cool.gz \
  --output-dir outputs/task2_resolution_audit
```

输出逐重复配对表、候选汇总和JSON协议到Git忽略目录；矩阵只在内存中局部池化，不生成新的真实数据文件。

## 结果

五候选各自的跨条件距离中心化相关先汇总为中位数，再计算候选间中位数：

| 分辨率 | 800 bp阈值对应偏移 | WT→ΔstpA | WT→ΔhnsΔstpA |
| ---: | ---: | ---: | ---: |
| 80 bp | 10 bins / 800 bp | 0.305 | 0.260 |
| 160 bp | 5 bins / 800 bp | 0.473 | 0.467 |
| 320 bp | 3 bins / 960 bp | 0.690 | 0.757 |

各分辨率的5候选跨条件值都为正；候选005在全部分辨率与两种突变对照中均最高。条件内重复中位数也随池化变粗而上升：WT为0.488、0.700、0.904；ΔstpA为0.288、0.440、0.661；双突变为0.320、0.577、0.828（按80、160、320 bp顺序）。这表明较粗分辨率会平滑纹理并提高相关，相关值不能脱离尺度直接比较；80 bp保留更多局部差异，320 bp下候选更相似，但其距离排除阈值也略大。

重要实现校验：10 bp源矩阵按16倍本地求和得到的160 bp结果，与已提交的160 bp全基因组池化矩阵审计逐候选完全一致（距离中心化相关最大绝对差为0）。这确认本地池化保留了坐标和求和计数定义。

结论仅为候选纹理在尺度变化下有正向重复相似性，但强度依赖分辨率。候选005排序相对稳定；其余候选相对强弱有变化。不得把更粗矩阵的较高相关解释为更可靠或更强的生物结构信号。
