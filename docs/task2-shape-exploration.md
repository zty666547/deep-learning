2026-10-10，协议`task2-shape-exploration-v1`。由原8项特征空间留出表现不足触发；使用同一187窗口和五折，因此不是新的未见测试集。实验前提交固定实现和参数，结果另行追加。不重新筛选主流程5个候选，不搜索参数。

## 预先固定的方法

从两个160 bp矩阵分别读取20,480 bp/128×128窗口；上三角排除偏移<5的像素（800 bp），最外侧两条偏对角线也不使用，以保证距离均值至少有3像素。

1. 原始空间组：`log1p`上三角按8×8位置块汇总，36项块均值，保留强度和位置。
2. 去距离纹理组：各偏对角线分别减自己的log均值；以窗口有效残差的RMS归一化，然后提取36项块均值与36项块RMS，共72项。纯距离包络的残差为0，不能填成虚假的纹理。这不是全基因组O/E，也没有去除所有覆盖偏差。
3. 两组分别对重复特征等权平均，以固定类别平衡L2逻辑回归做五段空间留出，训练区缩放、惩罚0.01、阈值0.5、缓冲20,480 bp均沿用前轮。
4. 另做去距离纹理的rep1→rep2与rep2→rep1空间留出：训练只用一种重复的训练区特征，测试只用另一种重复的新区域。它同时检查跨区域/跨重复迁移，不是独立条件外部验证。
5. 仅对去距离联合纹理做100次折内标签打乱，种子2026；保留原始空间组和两个迁移方向所有结果，不挑最好模型替换主结果。

## 复现

```bash
python scripts/benchmark_shapes.py \
  --cool data/processed/GSE272159_37C_rep1.160bp.cool \
  --cool data/processed/GSE272159_37C_rep2.160bp.cool \
  --windows outputs/task2_window_scan/candidate_windows.csv \
  --structures data/processed/structures.csv \
  --output-dir outputs/task2_shape_exploration \
  --blocks 8 --minimum-offset 5 --permutations 100 --seed 2026
```

保存输入SHA-256、参考/分辨率/库计数、特征NPZ、逐窗口预测、各折缩放/权重、打乱标签结果和图。数学测试验证纯包络无纹理、叠加log距离包络不改变纹理、主对角线不影响特征，微型COOL测试核验双重复与坐标。
