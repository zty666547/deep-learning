# 任务二：候选隔离后的单重复冻结簇迁移

日期：2026-10-13。实现和[协议](task2-task5-validation-protocol.md)事先冻结于`215a307`，之后运行一次真实核验；再在普通wheel安装环境按同一协议复算一次验收，不调参追平，不修改主5候选、主8特征簇。目的为补充跨条件归属证据，不声称解决新结构确认或原AUC 0.5582缺口。

## 方法与数据

原1,498个QC窗口按坐标贪心抽取200个不重叠窗口，另补3个不在网格中的固定候选代表，共203窗口。训练排除与5个候选区间及两侧20,480 bp保护带相交的窗口，最终仅用WT rep1的182个窗口。

固定7个单重复特征、训练专属中位数/IQR、3维PCA和k=2中心，分别投影六个来源，不使用双重复均值或相关性，测试条件不重拟合。此为**新诊断分区**，不能把这里的簇号当作主流程原8特征簇号。源数据为两份WT 160 bp COOL与任务三中四份突变160 bp COOL；输入哈希见[真实结果快照](task2-cluster-transfer-summary.json)。

QC逐来源独立计算。WT2参与过原候选/QC选择，WT一致性属于内部核验；两个突变条件没有拟合新诊断分区，但仍属于同一研究数据集，不是外部结构金标准。

## 可讲结论与边界

我们增加了候选隔离的训练和冻结跨条件赋值，证实部分特征分区在WT/单突变重复间可重复，同时发现双突变、候选边界和QC限制。特征含强度和距离衰减，条件标签变化不能归因于形态或突变机制。两个主簇含约75%已知窗口这一事实没有改变，原已知—背景可分性不足也未被解决。**这项核验完善了可追溯性和反证，但没有确认5种新结构。**
