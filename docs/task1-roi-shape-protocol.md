# 任务一：结构边界对齐与解释约束识别协议

2026-10-14，`task1-roi-shape-v1`。用户明确只优先完成任务一主项，暂不制作辅助标注工具、PPT或继续任务二。先冻结，再真实训练；不把效果目标写成已有结果。

## 诊断和文献依据

旧模型以20,480 bp完整窗口三分类，145/344标注跨类重叠。一对训练标注CHID_18与CHIN_172中心3188275/3188270落在同一160 bp网格，长度9550/1500 bp；旧输入相同而类别不同。它们不在测试集，不能据此解释全部测试错误，但证实固定中心窗没有完整表达待分类对象。

结构长度中位数CHID/CHIN/OPCID为8030/2080/4595 bp。参考[原研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC12460168/)，CHID为更高阶组织；针对重叠实例，借鉴[Mask R-CNN](https://arxiv.org/abs/1703.06870)按区域对齐特征的思想，不实现其检测/掩码网络，不复制COCO性能。

[Group Normalization](https://arxiv.org/abs/1803.08494)启发小样本单重复视图的非批统计归一化。[Right for the Right Reasons](https://arxiv.org/abs/1703.03717)启发训练时约束背景输入梯度。本实现使用目标log概率梯度的区域能量比，与原论文未归一化惩罚不同，不声称复现原论文效果。

## 输入与划分

读取既有真实80 bp、344×2×256×256 log1p张量；原248/55/41连续空间划分、全344身份/标签不变，不删除CHID或冲突样本。两套张量的身份/坐标/划分必须逐项与160 bp主张量一致；标注必须全部在原窗口内，不从保护带外读取额外像素。不同重复视图不是新增独立样本。

按标注起止的1.5倍范围切ROI（两端各加长度25%，仅裁至原窗口），64×64像素中心双线性采样。几何用[PyTorch grid_sample](https://docs.pytorch.org/docs/main/generated/torch.nn.functional.grid_sample.html) align_corners=False；不是完整四点RoIAlign。规则不使用类别名，标注边界是任务一已知输入；未经边界推断不能直接用于任务二未知区域。

在原80 bp窗口逐距离减log均值，仅用offset 2–253，排除<160 bp和最外两距离。再采样ROI、每重复以ROI上三角offset≥2的RMS归一、截断[-5,5]。这是单窗口log距离残差，不是全基因组balanced O/E；删除计数绝对水平不能保证消除噪声/分辨率信息，必须保留长度/密度基线。

## 模型、增强和验证选择

单通道RegionShapeCNN：三层stride2卷积16/32/64，GroupNorm/SiLU，2×2池化、256→64→3线性、dropout0.15。训练随机选WT1/WT2之一，随机同时反转两轴；预测分别推理双重复并平均logit，另报单重复结果与一致性。

冻结两种策略：同一ROI模型普通交叉熵，以及交叉熵+0.1背景梯度能量比。梯度区域掩码仅在训练惩罚中使用，模型推理不接收掩码/类别/长度标量，测试显著性不被掩码裁切。普通版作为解释约束消融，不选最好种子。

CPU1线程、确定性开关、种子2026/2027/2028；AdamW lr0.001/weight_decay0.0001，Cosine到0.00001，最多100轮/patience20；每步每类有放回12条，总36条，每轮ceil(248/36)步，交叉熵不再重复类别加权。验证按最低类别召回率优先、Macro F1次优的字典序保存权重，相同分数保留最早轮。

两策略三种子全部训练后，仅以各策略验证集最差种子的最低召回优先、三种子平均Macro F1次优选择主策略；此之前不评价测试集。之后全部六模型的测试结果同时保存，不能按测试分数替换主策略。既有测试区域已多次观察，本轮是开发改进而非全新盲测，不制造外部泛化结论。

## 形态、密度与解释核验

固定训练专属类平衡L2=0.01的一对其余逻辑回归：长度单特征log长度、ROI原log矩阵mean/std/nonzero三密度特征、长度+密度四特征；不使用染色体绝对位置/文件名/ID作为特征。报告验证与测试，不因控制较强而删去。分类性能提升若主要由标注尺度解释，不能称形态能力已证明。

对全部41测试结构、六模型生成真实类别绝对input×gradient图，错判也保留；相同初始化随机网络为架构/输入对照，按上三角offset≥2计算标注区域富集及模型间一致性。展示案例固定各类测试ID字典序首项，不挑预测正确者。

20次seed=9100+draw的对角距离保持打乱：全ROI、仅标注内、仅标注外；每个offset内使用同一排列处理双重复并镜像，保持变换后各重复逐距离的值分布/总和，包括零值。不是新真实样本，也不声称保持原始read计数或整个行和。以accuracy/Macro F1及真实类别logit降低核查形态依赖；三种子在结构内汇总，再跨结构/类别统计，抽样不当独立生物学重复。

工程目标（不是老师规定的数字）：每个种子每类Recall≥0.75、F1≥0.65，双重复预测一致率≥0.85；解释须有训练相对随机的区域富集与结构打乱影响，不能只凭好看热图宣称成功。若未达标，逐项记录，不放宽目标或按测试继续搜索。本轮预设最多两策略三种子，不无限试模型。
