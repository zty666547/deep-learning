1. GitHub代码仓库：环境、脚本、测试、运行命令和中文开发记录。

3. 实验报告：任务背景、数据、方法、实验、结果、讨论、局限和复现方式。
4. PPT：只保留支撑结论的流程图、核心结果和代表性案例。
5. 讲解视频：按“问题—方法—结果—限制—下一步”的顺序录制，不现场临时组织语言。

## 三、每个任务具体做什么

### 0. 数据与工程底座（已完成）

目的：确保后续实验使用同一坐标约定、同一真实数据和可复现命令。

步骤：

1. 读取两个37°C生物学重复的 `.cool` 文件。
2. 将课程Excel标注转换为统一结构表。
3. 按结构中心截取局部接触矩阵。
4. 对原始10 bp矩阵池化、`log1p`归一化并保存NPZ。
5. 按连续基因组区段划分训练、验证和测试，避免相邻窗口随机泄漏。
6. 保存数据哈希、形状、类别数量和完整运行命令。

讲解重点：为什么不能随机打散相邻基因组区域；为什么真实数据文件不上传GitHub。

### 1. 已知结构识别（当前约75%，10月9日封板）

已完成：CNN三分类、多随机种子、Focal Loss、分辨率/窗口对照、显著性检查、稳定错误分析和全量重叠审计。

剩余步骤：

1. 将344条互相重叠的标注整理为233个冲突感知区域。
2. 每个区域使用三个独立标签：CHID、CHIN、OPCID，可同时为1。
3. 继续使用20,480 bp窗口、160 bp分辨率和双重复通道。
4. 使用三个独立Sigmoid输出与加权二元交叉熵。
5. 在验证集上选择每类阈值，测试集只做一次最终评估。
6. 报告每标签Precision、Recall、F1，以及Macro F1和精确匹配率。
7. 与原互斥三分类仅做问题定义层面的对照，不直接比较不可比指标。

验收标准：三个集合都有三种标签；至少运行3个固定随机种子；输出模型、指标、混淆式标签表和代表性区域热图。

讲解重点：为什么重叠标注使互斥三分类产生矛盾；为什么多标签模型更符合当前标注结构。

### 2. 新型结构发现（10月10–12日）

目的：在已知CHID、CHIN、OPCID之外，从全基因组接触矩阵寻找稳定、可复查的候选模式。

步骤：

1. 沿染色体对角线按固定步长生成候选窗口，两个重复使用完全相同坐标。
2. 过滤计数过低、缺失过多或靠近边界的低质量窗口。
3. 从每个窗口提取接触强度、对角线衰减、对称性、局部纹理等可解释特征；时间允许时加入CNN嵌入。
4. 对特征标准化并降维，用聚类识别重复出现的模式。
5. 删除或标记与已知结构区域明显重叠的候选，避免把已知结构重新命名为“新结构”。
6. 分别在rep1和rep2计算候选特征与簇归属，保留跨重复一致的候选。
7. 输出候选坐标、所属簇、最近已知结构距离、一致性指标和双重复热图。
8. 将结果表述为“疑似候选”，不宣称发现了已验证的新生物学结构。

验收标准：有参数化脚本、候选CSV、聚类图、至少若干双重复热图和明确筛选规则。

讲解重点：未知结构没有标准答案，因此可信度来自排除已知结构、跨重复复现和可视化复查。

### 3. 接触频率与结构分布可视化（10月13日）

目的：把全局接触变化和结构位置放在同一坐标体系中展示。

步骤：

1. 按固定基因组窗口计算rep1、rep2接触强度轨道。
2. 绘制两个重复的全染色体趋势和重复差异。
3. 增加CHID、CHIN、OPCID及新结构候选的位置轨道。
4. 若能获得MG1655基因注释，再加入基因密度或重点基因轨道；若没有可靠注释，不伪造基因位置。
5. 选择2–3个代表区域绘制局部接触热图和结构标注。

验收标准：至少一张全局多轨道图、代表区域局部图和可复现绘图命令。

讲解重点：全局轨道回答“结构在哪里”，局部热图回答“接触模式长什么样”。

### 4. 选做任务五：接触矩阵超分辨率（10月14–15日）

选择理由：可由现有高分辨率窗口生成低分辨率输入，不依赖尚未提供的额外条件数据，十天内风险最低。

步骤：

1. 仅用训练集高分辨率窗口构造低分辨率输入，避免测试信息泄漏。
2. 建立双三次插值基线。
3. 训练轻量SRCNN或残差CNN恢复高分辨率矩阵。
4. 在固定测试集报告PSNR、SSIM和像素误差。
5. 并排展示低分辨率、插值、模型输出和真实高分辨率图。
6. 说明图像指标不等价于生物学真实性，不对不存在的细节作过度解释。

验收标准：至少一个插值基线、一个神经网络模型、量化指标和定性对比图。

讲解重点：模型是否真正超过简单插值，以及恢复结果在哪些区域仍失真。

## 四、报告结构

1. 摘要：数据、三个必做任务、一个选做任务和最主要结论。
2. 数据与预处理：文件、标注、坐标、划分、窗口和分辨率。

4. 任务二：候选生成、特征、聚类、排除已知结构和跨重复验证。
5. 任务三：全局与局部可视化。

8. 复现说明：环境、数据放置、关键命令和Git提交。
