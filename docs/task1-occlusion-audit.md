# 任务一：距离匹配受控遮挡核验

## 固定协议（先提交，再运行真实结果）

目的：已有绝对输入×梯度图与随机参数网络仍有较高相关，本轮检验归因热区是否比公平随机位置更影响模型。
使用相同41个测试结构和Focal seed 2026/2027/2028，真实类别logit固定，不重训、不调参。
已使用过的测试区仅作探索性方法核验，不能作为新的未见测试。

- 按模型保存的训练均值/标准差标准化双重复输入，重算真实类别绝对输入×梯度，通道平均并对称化。
- 只选择上三角、基因组距离≥800 bp（160 bp下offset≥5）的唯一像素对；近对角线保持原值。
- 固定选择归因最高的5%、10%、20%像素对，数量向上取整；同值按固定像素索引排序，零/常数归因不强行比较。
- 每个被选像素对在两个重复通道及对称位置同时替换成该样本、该通道、同一offset的原始输入中位数。
  该中位数在遮挡前计算一次；不用逐步更新的值、不填成零、不使用测试标签计算替换值。
- 两类随机位置对照各20次（seed=2026）：
  1. 精确匹配高归因集合在每个offset的像素数量；
  2. 同时匹配offset及替换能量的五分位层人数。替换能量为双通道标准化输入与同距中位数差的均方；五分位按offset内平均秩划分，同值同层。
- 对照从完整合格像素池无放回抽取，允许与高归因集合重合，记录重合比例；不排除热区来人为扩大差异。
- 增加输入强度对照：每个offset选同样数量、替换能量最大的像素，检查归因影响是否只反映输入幅度。
- 主指标是目标logit**绝对变化**。绝对归因不保留符号，不能预设遮挡一定降低目标logit。
  同时完整报告有符号logit降低与真实类别概率降低，及每次遮挡的实际替换能量。
- 各结构/模型/比例先计算“高归因绝对变化−随机20次的中位绝对变化”；三个模型在结构内取中位数，最后在41结构间报告中位差及差>0的比例。
  输入强度对照同样报告配对差。种子/遮挡抽样不是额外生物学样本；不报告p值或事后通过阈值。
- 保存全部遮挡结果、配对差、结构内汇总、选中掩码、输入/模型SHA-256、对照随机规则及图。

距离与能量匹配只降低混杂，仍未完全匹配邻域空间纹理或像素相依性；中位数替换也可能产生分布外输入。
结果只能支持或限制该解释方法对这些模型的局部有效性，不证明生物学机制，不修改分类模型或原测试分数。

## 运行方式与真实结果

协议先提交为`0addf35`。真实运行于10月10日完成，本轮10月12日续接后核对数据与三个模型SHA-256，
没有将既有结果冒充本轮新跑或新的未见测试。

```bash
PYTHONPATH=src python scripts/audit_saliency_occlusion.py \
  --dataset data/processed/task1_windows_full.npz \
  --checkpoint outputs/task1_imbalance_comparison/focal/seed_2026/model.pt \
  --checkpoint outputs/task1_imbalance_comparison/focal/seed_2027/model.pt \
  --checkpoint outputs/task1_imbalance_comparison/focal/seed_2028/model.pt \
  --output-dir outputs/task1_occlusion_audit \
  --minimum-offset 5 --draws 20 --seed 2026 --batch-size 8
```

总计15,498条扰动记录，未出现不可评估归因图。每窗口合格唯一像素对为7,626个，
5%/10%/20%实际遮挡382/763/1,526对；41结构内先汇总种子，再在结构之间统计。
下表的差是各结构配对差的中位数，**不是两个总体中位数相减**。

| 遮挡量 | 距离随机：绝对变化差 / 差>0结构 | 距离×能量层随机：绝对变化差 / 差>0结构 | 同距最高能量：绝对变化差 / 差>0结构 |
| --- | --- | --- | --- |
| 5% | 0.1723 / 40/41 | 0.1440 / 38/41 | 0.0906 / 37/41 |
| 10% | 0.2787 / 40/41 | 0.2188 / 37/41 | 0.1148 / 35/41 |
| 20% | 0.3941 / 40/41 | 0.3047 / 37/41 | 0.1041 / 34/41 |

![受控遮挡对照](figures/task1_occlusion_controls.png)

高归因位置比两类随机对照更影响目标分数，三个遮挡比例方向一致；
同距最高能量对照的替换能量更大，但多数结构的目标变化仍小于归因选择。
这为当前解释方法的**局部敏感性排序**提供支持，比仅展示显著性热图更有说服力；
并不证明所有热区都是支持目标类别的证据，也不证明染色质机制。

### 类别差异与变化方向

| 类别 | 结构数 | 距离×能量对照差（5% / 10% / 20%） | 高归因遮挡目标logit降低中位数（5% / 10% / 20%） |
| --- | ---: | --- | --- |
| CHID | 4 | 0.7044 / 0.9812 / 1.2339 | 0.9267 / 1.3474 / 1.9305 |
| CHIN | 30 | 0.1166 / 0.1886 / 0.2678 | -0.1305 / -0.2302 / -0.3760 |
| OPCID | 7 | 0.5225 / 0.5856 / 0.5586 | -0.7932 / -0.9916 / -1.1543 |

负的“降低”表示目标logit升高。CHID遮挡后目标logit和概率中位数降低；OPCID反而升高，
不能把所有绝对归因统一解释成正向支持。CHIN的目标logit升高但概率降低也不矛盾：
概率还取决于其他两个类别分数。CHID仅4例，不据此宣称稳定的类别规律。

### 对照仍有哪些不足

- 能量五分位匹配不是逐像素能量精确相等：高归因/分层随机替换能量中位数分别为
  0.4331/0.3431、0.3498/0.2944、0.2810/0.2500。残余幅度混杂仍需限定，不能省略。
- 分层随机与热区的重合中位比例为24.35%、31.19%、40.96%；随机池包含热区是预定规则，
  不是另挑“不重要像素”来夸大效果。远距离层的小像素池也会限制可选位置。
- 原`输入×梯度`以标准化零为隐含参考，遮挡使用同距中位数；本实验是局部扰动核验，
  不是该归因算法的数学完备性证明。像素替换也没有完全匹配空间邻域、接触纹理或输入分布。
- 当前缺少其他归因方法、预测类别目标和不同基线的独立验证。保留上一轮随机参数相关较高的发现，
  不因本轮支持性结果撤回限制，也不调整原分类性能或以遮挡后的分类结果作为新测试准确率。

输出包含逐次扰动、1,107条模型内配对、369条结构级配对、36条分组汇总、固定掩码及输入哈希。
完整分组数值另存于[汇总表](task1-occlusion-group-summary.csv)。讲解时可说：
“我们不仅看热图，还比较了相同距离、相近扰动能量的随机遮挡。热区通常更影响模型判断，
但变化方向因类别而异，所以它说明模型敏感的位置，不直接说明这些位置的生物学作用。”
