# 任务二：聚类、已知结构排除与候选规则

## 一、方法设计

对1,807个质检通过窗口使用8项可解释特征：总接触数的对数、非零比例、近/远距离比值的对数、距离衰减斜率、中心富集、变异系数、接触熵和rep1/rep2相关性。

处理步骤：

1. 每项特征使用中位数和四分位距进行稳健标准化。
2. PCA保留累计解释方差至少90%的主成分，最多保留6个。
3. 对 `k=2–8` 分别运行10次确定性K-means++初始化。
4. 使用平均轮廓系数选择聚类数量，而不是人工挑选视觉上最好看的结果。
5. 计算每个窗口与最近“已知结构重叠窗口”在PCA空间中的距离，作为特征新颖度分数。

## 二、聚类结果

PCA保留3个主成分，累计解释95.14%的特征方差。各聚类数量及轮廓系数：

| k | 轮廓系数 |
| ---: | ---: |
| 2 | 0.3492 |
| 3 | **0.4167** |
| 4 | 0.3286 |
| 5 | 0.3364 |
| 6 | 0.3301 |
| 7 | 0.3022 |
| 8 | 0.2921 |

最终选择3簇，包含192、1,098、517个窗口。三个簇中与已知结构重叠的窗口比例分别为61.46%、73.68%、75.24%。聚类用于描述常见形态，不直接把某个簇命名为新生物学结构。

## 三、“疑似新结构”的可操作判定规则

一个窗口必须同时满足：

1. 通过基础完整性和稀疏度质检。
2. 整个20,480 bp窗口与344条CHID、CHIN、OPCID标注均无直接区间重叠。
3. rep1/rep2上三角 `log1p` 接触矩阵相关性不低于0.90。
4. 到最近已知结构重叠窗口的PCA距离，位于满足前3项窗口的最高10%。

满足规则的窗口按起点间距不超过5,120 bp合并；合并区域至少需要2个窗口支持，避免把单个离群窗口当作结构。

这一规则清晰、可复算，但其中0.90、前10%、5,120 bp和至少2个支持窗口仍是分析阈值，必须通过敏感性分析说明结论是否稳定。

## 四、真实数据候选

1,807个窗口中，491个与已知结构完全不重叠。应用重复一致性和新颖度规则后得到35个候选窗口，合并为6个疑似候选区域：

| 候选 | 区间 | 支持窗口 | 代表中心 | 簇 | 新颖度 | 重复相关性 | 最近已知结构距离 |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 001 | 7,680–35,840 | 3 | 25,600 | 0 | 0.8470 | 0.9514 | 13,820 bp |
| 002 | 207,360–232,960 | 2 | 222,720 | 0 | 0.8220 | 0.9577 | 4,040 bp |
| 003 | 2,711,040–2,746,880 | 7 | 2,728,960 | 0 | 2.6883 | 0.9802 | 8,230 bp |
| 004 | 3,601,920–3,630,080 | 3 | 3,619,840 | 0 | 0.9601 | 0.9429 | 1,180 bp |
| 005 | 3,929,600–3,955,200 | 3 | 3,942,400 | 0 | 1.5083 | 0.9798 | 5,050 bp |
| 006 | 4,152,320–4,195,840 | 10 | 4,170,240 | 0 | 2.8300 | 0.9873 | 34,360 bp |

候选003和006的新颖度、重复相关性和连续窗口支持均较高，优先进入热图复核；候选004距离最近已知结构仅1,180 bp，需要特别警惕边界效应。

## 五、结论边界

- 以上6个区域是参数化流程产生的“疑似候选”，不是经独立实验确认的新结构。
- 相邻窗口高度重叠，支持窗口数量不能当成独立重复次数。
- 全部最终区域落在簇0，说明当前新颖度主要对应同一类特征形态，但不能仅据此给该簇赋予生物学名称。
- 下一轮必须生成双重复热图、进行阈值敏感性分析，并检查候选是否由局部覆盖峰或染色体边界造成。
