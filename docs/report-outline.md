# 实验报告写作提纲（按当前真实结果）

这份提纲对应课程评分中的“问题定义、方法设计、实现与可复现、实验评价、解释与展示”，写作时每一节都引用仓库中的同一份结果文件，不手工改写数值。它不是正式成稿；任务覆盖与未验收项见[质量清单](quality-review.md)。

## 1. 摘要

说明输入是大肠杆菌MG1655的Micro-C接触矩阵，使用37°C rep1/rep2，完成已知结构识别、疑似新结构候选扫描、结构与接触频率可视化，并选做160 bp到80 bp超分辨率。摘要只写三条最稳妥结论：多标签任务解决了重叠标注冲突；任务二得到5个待复核候选且candidate_004对阈值最稳定；超分辨率CNN在内部测试中优于双三次基线。

## 2. 问题定义与数据

- 输入：`.cool` Micro-C矩阵、`structures.csv`已知结构。
- 已知标签：CHID 26、CHIN 250、OPCID 68。
- 原始分辨率10 bp；任务一窗口20,480 bp，池化至160 bp。
- 说明零起点、左闭右开坐标和两个生物学重复。
- 明确哪些数据是真实数据，哪些仅为接口夹具；不把合成夹具写成实验结果。

## 3. 设计思路

### 3.1 标注冲突与任务一

全量审计发现111对跨类别重叠，验证/测试CHID全部受冲突影响，因此增加区域级三标签作为补充分析，不直接替代课程要求的三分类。分别交代原始标注分类与区域多标签的问题定义、结果和局限。说明合并区域、BCE正样本权重、验证集独立阈值和三随机种子设计。

### 3.2 疑似新结构发现

说明`task2-main-v1`同坐标滑窗、质量控制、可解释特征、PCA/K-means、已知区间排除、跨重复相关和敏感性分析。历史226窗口流程不混入主结果。把“疑似候选”判定条件写成可执行规则，并补充去近对角线/距离中心化核验：只支持重复一致，不构成新颖性的独立证明。

### 3.3 选做超分辨率

说明160 bp输入、80 bp目标、共同样本与坐标核对、跨划分重叠检查、计数尺度校正、公平双三次基线、对称残差CNN、训练集共享尺度，以及逐样本逐重复PSNR/局部SSIM/MSE定义。
