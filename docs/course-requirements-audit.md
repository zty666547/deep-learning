## 四、远程目录核验命令

```bash
python scripts/inspect_remote_tar.py \
  --url https://ftp.ncbi.nlm.nih.gov/geo/series/GSE272nnn/GSE272161/suppl/GSE272161_RAW.tar \
  --output outputs/course-data-archive-manifest.json
```

该工具只支持未压缩TAR的HTTP分段元数据读取；服务器若忽略Range返回整包，立即拒绝读取。不解压、不执行成员；支持标准和GNU长文件名，不支持PAX时明确报错，避免静默漏读。
