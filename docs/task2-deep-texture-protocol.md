# 任务二训练区专属深度纹理表征：冻结协议

日期：2026-10-14。协议`task2-purged-replicate-contrastive-v1`。这是在原8特征及36/72手工纹理结果偏弱之后进行的一次固定探索。沿用187个已观察过的空间网格，不能视为新盲测；主5候选、原AUC和簇身份不替换。

## 方法与反泄漏

1. 固定原187个不重叠窗口、141已知重叠/46无标注背景、五个基因组区块及20,480 bp训练缓冲。每折编码器只读取该折训练区的两WT重复；结构标签不是编码器训练接口的参数。
2. 每个128×128单重复计数矩阵先log1p，再按距离减均值（去<800 bp及仅1–2像素外围偏移），以有效残差RMS归一、固定裁剪[-5,5]，2×2平均为64×64。纯距离包络无残差时保留零纹理，不制造形态。
3. 固定单通道三卷积（8/16/32通道，步长2，GroupNorm+ReLU）、2×2自适应池化、128维空间表征；仅训练用投影为128→64→32。参考[SimCLR论文](https://arxiv.org/abs/2002.05709)的投影/对比学习思想，正对为同坐标两生物学重复，不是ImageNet式增广，也不声称复现原论文性能。
4. NT-Xent取两方向全部anchor平均，温度0.2、自相似屏蔽、其他窗口为负对。AdamW lr=0.001、weight_decay=0.0001，最多32窗口/批，以等大小块避免单例末批，全部训练窗口每轮使用；固定20轮、CPU单线程/确定性算法，seed=2026+fold，不早停或根据测试选权重。
5. 训练前拷贝同一初始化网络为随机参数对照。各折保存训练/测试ID、网络权重/初始化、128维双重复特征、20轮损失和表征方差/配对检索等诊断；heldout的统计不会参与编码器或特征缩放拟合。
6. 固定类别平衡L2逻辑回归（惩罚0.01、训练中位数/IQR、阈值0.5）评价四组：训练网络双重复均值、随机网络双重复均值、训练网络rep1→rep2、训练网络rep2→rep1。全部方向/随机对照/五折结果公开。
7. 仅对训练网络联合表征做20次折内标签打乱，seed2026，每次重新拟合各折分类器；编码器不见标签。对照只提供稀疏描述性范围，不保存全部空间依赖、不计算生物学p值。

不使用测试结果选择网络/轮数/温度/阈值；不扩展架构搜索直到出现有利AUC。无标注不是真阴性，任意标注重叠的窗口标签有尺度歧义，五折训练得到的编码器空间也不能直接拼接为一个全局新结构簇空间。即使可分性提高，也不代表新结构簇已建立或生物学真实性获证。

## 运行

```bash
OPENBLAS_NUM_THREADS=1 PYTHONPATH=src python scripts/benchmark_contrastive_textures.py \
  --cool data/processed/GSE272159_37C_rep1.160bp.cool \
  --cool data/processed/GSE272159_37C_rep2.160bp.cool \
  --windows outputs/task2_window_scan/candidate_windows.csv \
  --structures data/processed/structures.csv \
  --output-dir outputs/task2_deep_texture_new
```

入口只接受新目录，失败写`failure.json`，不覆盖旧结果或省略失败。大体积输入/权重/特征留在忽略目录，公开小型结果、图表和解释。
