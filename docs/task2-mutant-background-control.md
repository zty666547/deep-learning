# 任务二：独立突变条件候选—背景对照

日期：2026-10-10。目的不是再挑候选，而是检验WT中选出的5个候选代表窗口，在未参与选择的突变条件重复中，其距离中心化纹理是否比普通无标注窗口更一致。

## 固定比较方案

- 窗口与类别来自主流程`task2-main-v1`：仅使用质量合格窗口；选取5个候选代表窗口，以及所有不与任一候选区间相交、且不与任何已知结构相交的无标注窗口。
- 实际纳入5个候选代表和329个背景窗口。两组窗口均为20,480 bp、128×128、160 bp bin；背景与候选区间隔离，但背景窗口之间可能重叠。
- 只检验ΔstpA和ΔhnsΔstpA各自的两重复一致性，不把已用于选择候选的WT重复放进本项对照。逐像素log1p，排除偏移<5 bins（800 bp），再按每个偏移的均值中心化后计算Pearson r。
- 同时报告原始计数和按每个重复全库上三角总计数归一到CPM后的结果。该CPM敏感性检查只校正总库量，不校正局部覆盖或距离偏差。
- 所有统计量均为描述性窗口分布；没有p值。背景不是已证实阴性，窗口有空间重叠，候选仅5个，不能据此推断新结构或突变因果效应。

## 复现

```bash
PYTHONPATH=src .venv/bin/python scripts/audit_mutant_candidate_background.py \
  --windows outputs/task2_clustering/window_clusters.csv \
  --candidate-regions outputs/task2_clustering/candidate_regions.csv \
  --dstpa-rep1 data/processed/task3-160bp/GSM8950761_DstpA_rep1.MG1655.mapq_30.160.cool \
  --dstpa-rep2 data/processed/task3-160bp/GSM8950762_DstpA_rep2.MG1655.mapq_30.160.cool \
  --double-rep1 data/processed/task3-160bp/GSM8950763_DhnsDstpA_rep1.MG1655.mapq_30.160.cool \
  --double-rep2 data/processed/task3-160bp/GSM8950764_DhnsDstpA_rep2.MG1655.mapq_30.160.cool \
  --output-dir outputs/task2_mutant_background --minimum-offset 5
```

输出包括逐窗原始/CPM指标、组汇总、各条件图和协议JSON，全部位于Git忽略目录`outputs/task2_mutant_background/`。

## 结果

核心指标为排除近对角线并按距离中心化后的Pearson r。表中的四分位数描述各窗口分布，不代表独立生物学样本置信区间。

| 归一化 | 条件 | 候选中位数（Q1–Q3，n=5） | 无标注背景中位数（Q1–Q3，n=329） | 中位数差 |
| --- | --- | ---: | ---: | ---: |
| 原始计数 | ΔstpA | 0.515（0.462–0.795） | 0.309（0.201–0.453） | 0.205 |
| 原始计数 | ΔhnsΔstpA | 0.612（0.580–0.730） | 0.292（0.179–0.396） | 0.320 |
| 库总量CPM | ΔstpA | 0.787（0.655–0.919） | 0.540（0.357–0.718） | 0.247 |
| 库总量CPM | ΔhnsΔstpA | 0.849（0.715–0.894） | 0.517（0.308–0.690） | 0.332 |

两种突变条件、两种归一化下，候选代表窗口的中位重复一致性都高于背景中位数。CPM后候选—背景差距仍为正；因此本轮观察不只由WT候选选择时使用的那一组重复，或单纯由两个突变重复总库量差异造成。不过，候选组极小且背景窗口互相重叠；这只是支持“部分固定候选在独立突变条件下具有较可重复纹理”的描述性证据，不能等价为生物学新结构验证。

## 讲解时可以这样表述

“为了避免把候选窗口的重复性误当成新结构证据，我们将5个固定候选代表窗口与329个避开已知标注和候选邻域的窗口比较，并在没有参与候选选择的两种突变条件中检查双重复。候选组的距离中心化相关中位数在四种设置下都高于背景，且CPM归一后方向仍一致；但背景窗口互有重叠、候选只有5个，所以我们把它作为可重复性支持，而不是统计显著的结构发现。”
