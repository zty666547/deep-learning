# 任务二：已知覆盖与区域留出特征对照

日期：2026-10-10。核验协议`task2-feature-benchmark-v1`，输入为`task2-main-v1`完整1807窗口表和344标注。不改变25命中窗口/5疑似区域的筛选，不把诊断分类器替换成新结构检测器。

## 固定协议

全基因组滑窗必然覆盖大量标注，覆盖率高不等于识别能力。相邻滑窗共享约87.5%的位置，随机分训练/测试会泄漏像素；全局PCA同样不能直接用于留出分类器。本轮分别检查扫描覆盖、质量过滤损失和特征的区域泛化。

- 从1498质量合格窗口取起点为20,480 bp整数倍的完整窗口，得到187互不重叠窗口；141已知重叠、46无标注背景。标签按任意正长度重叠定义；无标注不等于确定阴性，不挑选背景。
- 染色体五等分按中心确定5折，测试窗口32/40/39/38/38。每次排除距测试窗口范围不足20,480 bp的训练窗口，各折均有两类。
- 每折只在训练区拟合中位数/IQR，不用全局PCA；类别平衡L2逻辑回归，固定惩罚0.01和阈值0.5，不按测试结果调参。
- 密度组用log总计数与非零比例；形态/重复组用其余6项（近远带比、衰减斜率、中心富集、变异系数、接触熵、重复相关性）；全特征组用原8项。
- 各折内打乱标签、保留阳性数量，以种子2026重新训练100次。这是不保持完整空间相关的描述性对照，不报告生物学显著性或独立样本置信区间。

## 真实结果

| 特征组 | 五折AUC均值±折间样本标准差 | 汇总留出召回 | 特异度 | 平衡准确率 |
| --- | ---: | ---: | ---: | ---: |
| 密度2项 | 0.4083 ± 0.1045 | 0.4397 | 0.5000 | 0.4699 |
| 形态/重复6项 | 0.4971 ± 0.1089 | 0.6170 | 0.3913 | 0.5042 |
| 原8项全特征 | 0.5582 ± 0.0964 | 0.5957 | 0.4783 | 0.5370 |

全特征逐折AUC为0.5556/0.6580/0.4188/0.6378/0.5207。打乱标签平均AUC均值0.5065，2.5%–97.5%经验范围0.3677–0.6064。观察值0.5582在范围内，**目前不足以确认原8项特征具有稳定的已知/背景区分能力**。这不是所有表征无效的证明，也不能事后翻转评分或反复调参包装成功。

常数全部阳性预测的召回1、特异度0、平衡准确率0.5，说明不能只报召回。五折AUC等权均值是主统计；不同折分数尺度未必相同，混合留出分数的AUC仅作辅助。折间标准差不是生物学重复间标准差或数据置信区间。

## 标注区间并集覆盖

每条标注与阶段窗口并集的交集长度，除以标注长度；重叠窗口不会重复计数，也适用于较长CHID。以下是至少50%长度被覆盖的条目比例：

| 阶段 | CHIN（250） | OPCID（68） | CHID（26） |
| --- | ---: | ---: | ---: |
| 全滑窗 | 100% | 100% | 100% |
| 质量通过滑窗 | 94.4% | 100% | 96.15% |
| 不重叠核验网格 | 75.6% | 95.59% | 61.54% |
| 全特征留出预测阳性窗口 | 51.2% | 57.35% | 57.69% |

前两行是提议覆盖，不是学习检出召回。最后一行是固定网格诊断分类器的对象覆盖，不等同于有意排除已知的无监督新颖筛选。网格/QC损失与分类损失要分开解释。90%覆盖阈值和每条标注的数值也保存。

## 复现与证据

```bash
python scripts/benchmark_discovery.py \
  --windows outputs/task2_window_scan/candidate_windows.csv \
  --structures data/processed/structures.csv \
  --output-dir outputs/task2_feature_benchmark \
  --window-bp 20480 --purge-bp 20480 --folds 5 --permutations 100 --seed 2026
```

必须用完整扫描表，不能误用25行候选表。`summary.json`记录输入SHA-256、参数、各折训练/测试ID、缩放与权重；`out_of_fold_windows.csv`记录预测；`annotation_coverage.csv`记录各阶段覆盖。审阅快照：[汇总JSON](task2-feature-benchmark-summary.json)、[对照图](task2-feature-controls.png)。原始矩阵与运行输出保持Git忽略。
